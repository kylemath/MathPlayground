    About

    Drag the canvas to orbit. Mouse wheel zooms. Perspective diagonals are camera-sightline rays through collinear lattice points. Orthographic raster diagonals are an arithmetic artefact of how the raster wraps (multiples of small primes shift by L mod p per row). The 3D Ulam snake is a true continuous path from the origin (consecutive integers always touch), so it shows genuine prime-polynomial spokes; the cubic-shell variant grows the same shells but visits each in disconnected pieces.
